# game-teardown

一个用于生成 **「游戏策划视角」游戏拆解 / 竞品分析报告** 的 Claude Skill。

面向求职作品集、竞品调研和面试准备，核心目标是把拆解从"游戏说明书"（玩家也能写的现象罗列）拉到"设计分析"（看懂意图、看懂结构、提炼可迁移结论）。

## 这个 skill 帮你做什么

- **能深拆任何类型的游戏**：常见品类按"设计原型簇"快速定位维度权重，冷门/混合/新品类用通用框架（设计基本九问）兜底
- 强制每个观察回答"为什么这么设计"，而不只是"它长什么样"
- 数值 / 经济用模型（资源水池、成长曲线）说话
- 信息严格分【事实 / 推断 / 假设】三级，绝不把猜测当官方数据
- 可选生成「面试讲解版」：2 分钟口述稿 + 预判追问及答法
- 用 mermaid 画核心循环图与系统依赖图（GitHub 直接渲染）

## 结构

```
game-teardown/
├── SKILL.md                          # 主流程：定对象→定品类→收集信息→按维度拆→输出
└── references/
    ├── universal-framework.md        # 通用九问：保证任何游戏都拆得了（兜底层）
    ├── by-genre.md                   # 七大设计原型簇 + 重型复合体的维度权重
    ├── dimensions.md                 # 各维度的拆解要点
    ├── numerical-and-economy.md      # 数值与经济深拆（含模拟经营/策略向）
    └── examples.md                   # 说明书式 vs 策划式 对照范例
```

## 怎么用

把 `game-teardown/` 文件夹放进你所用环境识别 skill 的目录（如 Claude Code 的 skills 目录），之后对话里说"拆解一下 XX 游戏""帮我分析 XX 的数值/商业化""做个竞品对比"等即可触发。

## 触发示例

- "帮我拆解一下《某游戏》，要放进作品集"
- "只拆 XX 的抽卡商业化，我面试要用"
- "对比一下这两款 SLG 的经济系统"
