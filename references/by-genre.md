# 按品类调整拆解维度（全覆盖）

拆解前先定品类，再据此调整维度权重——拿手游那套"抽卡/付费墙/水池"去拆买断单机会严重跑偏。

**找不到对应品类、或拿不准、或是混合/新品类时，回到 `universal-framework.md` 用通用九问兜底，照样能深拆。** 本文件是常见品类的快捷路径，不是封闭清单。

游戏按"设计原型"分七大簇 + 两类重型复合体。先用 `universal-framework.md` 的"归位法"找到所属簇，再看簇内具体品类的命门。

## A 操作技巧簇
**包含**：动作(ACT)、FPS/TPS、格斗、音游、竞速、体育、平台跳跃(平台跳台)。
**共同命门**：精通靠**操作技巧**，所以核心拆"手感 + 技能上限 + 难度曲线 + 心流"。
**权重**：玩法/战斗◎、关卡/难度曲线◎、情绪曲线○、表现层(打击感/反馈)◎；数值△、经济✕、商业化△(多为买断/DLC/外观)、留存△。

- **动作/ACT**：连段与取消的深度、风险回报设计（如完美闪避换反击）、Boss 战的"教学-考核"节奏。
- **FPS/TPS**：枪械手感与后坐力、地图视线与节奏、TTK 对玩法风格的影响。
- **格斗**：帧数据与博弈（出招优先级、确反）、技能上限与新手友好的平衡。
- **音游**：判定区间与手感、谱面难度梯度与"可读性"、曲库与表现的情绪带动。
- **竞速**：模拟度 vs 上手门槛、操作手感与赛道设计、生涯/赛事模式的长线。
- **体育**：拟真与可玩的取舍、操作深度、生涯/经理模式（后者偏向 C 簇/D 簇）。
- **平台跳跃**：操作精度要求、关卡作为"机制教学"的编排、死亡惩罚与重试节奏。

## B 策略智力簇
**包含**：回合策略/战棋(SRPG)、4X、RTS、塔防、自走棋、卡牌构筑/TCG、Roguelike/Roguelite。
**共同命门**：精通靠**决策**，核心拆"决策深度 + 平衡 + 是否存在统治解 + 信息与博弈"。
**权重**：玩法/决策◎、平衡性◎、系统结构○、数值○(平衡向)；经济○、商业化△、留存○(竞技向)。

- **战棋/SRPG**：地形与站位的策略空间、概率(命中/暴击)如何制造张力又不失控、永久死亡/资源稀缺带来的决策权重。
- **4X**：探索-扩张-开发-征服四阶段的节奏、是否有"滚雪球后一边倒"的失衡、胜利路径的多样性。
- **RTS**：运营 vs 操作(APM)的配比、兵种相克与经济节奏、平衡补丁逻辑。
- **塔防**：路径与放置的策略、波次/数值的难度曲线、新塔/新机制的引入节奏。
- **自走棋**：经济运营（利息/连胜连败/D 牌时机）、随机与策略的平衡、阵容 meta 的演化。
- **卡牌构筑/TCG**：卡池与构筑深度、meta 健康度（是否一套独大）、卡牌经济与平衡补丁、抽卡/卡包变现如何不破坏竞技公平。
- **Roguelike/Roguelite**：局内构筑深度（道具/天赋的协同与 build 成型路径）、随机性与 build 平衡（随机给变数但不让人觉得"不公平翻不了盘"）、单局张力曲线（滚雪球与翻盘窗口）、局外元进度（meta 解锁）如何在反复"重开"中维持目标感。**注意混合体**："幸存者like（割草）+ 抽卡手游""Roguelite + 长线养成"是当下大量出现的形态，要叠 C 簇的养成与商业化，先用 `universal-framework.md` 拆支柱、点明"用 Roguellike 局内体验做皮、内核是手游养成变现"。

## C 养成数值簇
**包含**：F2P RPG 手游、ARPG 刷宝、二次元养成(二游)、放置/挂机、SLG。
**共同命门**：进度靠**数值养成 + F2P 变现**，这就是 SKILL.md 默认框架的本命。核心拆"成长曲线 + 经济水池 + 商业化分层 + 留存钩子"。
**权重**：核心循环◎、系统结构◎、数值与成长◎、经济◎、商业化◎、留存◎；玩法○。

- **RPG 手游**：多条养成线如何吃量、付费墙位置、日常/周常驱动的留存节奏。
- **ARPG 刷宝**：装备词条/掉落的随机性与追求曲线、Build 多样性、赛季重置的经济意义。
- **二游**：角色养成线、情感/收集付费、卡池与保底设计、剧情与角色作为留存内容。
- **放置/挂机**：离线收益的产出节奏、数值膨胀与重置(转生/突破)循环、低操作下如何维持目标感。
- **SLG**：玩家驱动的战争经济、同盟社交、付费如何转化为战力与时间差、大 R 生态。

## D 系统模拟簇
**包含**：模拟经营、建造、生存、沙盒、城市建设、模拟器(农场/飞行)。
**共同命门**：核心是**系统自洽与涌现**，而非战力膨胀。核心拆"经济闭环平衡 + 是否有无脑最优解 + 自由度与涌现 + 难度靠规则还是数字"。
**权重**：系统结构◎、数值与成长◎(平衡向)、经济◎、核心循环◎；新手引导◎(系统复杂)、商业化△、留存○。

- **模拟经营/策略**：各产业/资源的供需网络、最优解是否破坏可玩性、AI/对手靠智能还是数值作弊、随机事件分布、决策权重。详见 `numerical-and-economy.md` 第五节。
- **建造/沙盒**：自由度与目标感的平衡、涌现式玩法（系统交互产生设计者没预设的玩法）、UGC/分享生态。
- **生存**：生存压力(饥饿/温度/威胁)的节奏、资源采集-加工-建造循环、早期紧张到中期掌控的曲线。
- **城建**：规模与复杂度的渐进解锁、平衡(交通/经济/民意)的多目标博弈、失败的容错与反馈。

## E 内容体验簇
**包含**：叙事/AVG/galgame、解谜、步行模拟、恐怖、线性剧情向单机。
**共同命门**：核心是**内容与情绪**。数值/经济/商业化几乎全不适用，硬写就是凑数。核心拆"情绪/体验曲线 + 叙事结构 + 引导与难度梯度 + 玩法与主题的呼应"。
**权重**：情绪曲线◎、题材/叙事◎、玩法○、关卡/难度曲线○(解谜)、新手引导○；数值✕、经济✕、留存✕、商业化△(买断/章节解锁)。

- **叙事/AVG/galgame**：分支与选择的意义（真分支还是伪选择）、信息释放与情感铺垫节奏、角色塑造手段。
- **解谜**：谜题难度梯度、引导设计（如何让玩家"卡住但不放弃"）、机制的渐进教学。
- **恐怖**：紧张-释放的节奏编排、未知与可见威胁的配比、资源稀缺如何放大恐惧。
- **步行模拟/线性剧情**：节奏控制、玩法如何服务叙事而非打断、环境叙事手法。

## F 社交竞技簇
**包含**：MOBA、大逃杀(BR)、竞技 FPS、派对/合作游戏、强社交游戏。
**共同命门**：核心是**人与人的对抗或协作**。核心拆"平衡性 + 匹配与公平 + 社交摩擦设计 + 长线 meta 与观赏性"。
**权重**：平衡性◎、玩法◎、留存◎(社交粘性)、系统结构○；商业化○(外观/通行证)、数值△、经济△。

- **MOBA**：英雄平衡与版本 meta、匹配与天梯、团队协作与个人 carry 的平衡、观赏性(电竞)。
- **大逃杀**：缩圈节奏、随机(物资/落点)与技巧的配比、单局张力曲线。
- **竞技 FPS**：见 A 簇手感，叠加平衡、反作弊、赛季与排位留存。
- **派对/合作**：社交摩擦设计（如《Among Us》的欺骗、《胡闹厨房》的协作压力）、低门槛高上限、即时同乐的爽感。

## G 休闲泛用户簇
**包含**：三消(match-3)、超休闲、合成(merge)、混合休闲。
**共同命门**：极简上手、面向泛用户、**变现逻辑和重度手游完全不同**（广告 + IAP 混合变现、关卡墙、而非战力付费）。核心拆"关卡难度调控 + 混合变现 + 留存钩子 + 即时反馈爽感"。
**权重**：核心循环◎、关卡/难度曲线◎、商业化◎(广告+IAP)、留存◎、新手引导◎；系统结构△、数值○(关卡数值)、经济△。

- **三消/合成**：关卡难度的"动态调控"（适时给难关卡引导付费/看广告）、步数/道具经济、外层元玩法(装修/剧情)如何挂载留存。
- **超休闲**：极限简化的核心循环、广告变现节奏(插屏/激励视频频率与留存的平衡)、买量逻辑。
- **混合休闲**：休闲皮 + 中度内核(养成/收集)的嫁接，看它如何把超休闲的获客和中度的变现/留存结合。

## 重型复合体
开放世界和 MMORPG 横跨多簇，按"复合体"处理：先用 `universal-framework.md` 拆出它的多个支柱，再取相关簇权重的并集。

- **开放世界**：核心是**探索设计**——兴趣点(POI)密度与分布、世界引导(如何不靠任务列表也知道去哪)、内容铺陈避免空旷、主线与支线/涌现的配比。叠加其底层品类(动作/RPG/生存)的权重。服务型开放世界(如手游开放世界)再叠 C 簇的养成与商业化。
- **MMORPG**：几乎全维度都重——叠加 C 簇(长线养成)、F 簇(社交/公会/PvP)、D 簇(玩家驱动经济/拍卖行)，外加副本/Raid 设计、社交系统、长线运营。拆解时务必先定支柱，否则会写成无重点的百科。

## 通用提醒
- 不确定品类，先回答"靠什么留住玩家、靠什么(或是否)赚钱、精通靠操作还是决策"，基本能定位。
- 任何混合/新品类都先走 `universal-framework.md` 的九问 + 支柱定位，再来这里取权重。
- 本文件的权重（◎○△✕）是"输出报告挂哪些维度模块"的依据；具体挂载形态见 `output-templates.md` 的维度块菜单。两者改动时保持同步，避免漂移。
