# 通用拆解框架（任何游戏都适用）

**没有"拆不了"的游戏。** 不管是冷门品类、跨品类混合、还是没见过的新形态，都能拆——因为所有游戏本质上都在回答同一组设计基本问题。`by-genre.md` 是常见品类的快捷路径；遇到清单上没有、或拿不准归哪类的游戏，用本框架兜底，照样能深拆。

## 一、通用九问（任何游戏都先回答这九个）

逐个回答，答案就是这款游戏的设计画像。

1. **核心动词与幻想**：玩家主要在"做什么"（射击/建造/经营/解谜/养成/探索/竞争/收集/社交/表达/指挥……）？它满足的是哪种欲望或幻想？这是一切的起点。
2. **核心循环**：最小的"行动→反馈→变化→新行动"链是什么？短/中/长三层循环如何嵌套？
3. **挑战从哪来**：难度的来源是操作、策略决策、知识/信息、资源管理、运气、还是社交博弈？通常是几种的配比。
4. **精通如何成长**：玩家"变强"靠的是技巧提升、数值成长、知识积累、还是装备/build？精通曲线（上手到精通的坡度）长什么样？
5. **进度如何衡量**：玩家凭什么感到"我前进了"——数值、解锁、剧情推进、收集度、排名、创造物、还是单纯的手感自觉？
6. **靠什么不腻**：避免重复枯燥的手段是随机性、内容量、玩家创造(UGC)、对手多样性、还是 meta 演化？
7. **靠什么留人**（若适用）：为什么明天还来？买断制单机可能根本不需要这一条，硬套留存维度就是错。
8. **怎么赚钱 / 是否赚钱**：买断、F2P 内购、广告变现、订阅、DLC、UGC 分成？付费与体验如何耦合（强/弱 P2W、纯外观、关卡墙、广告插入点）？
9. **情绪目标**：设计最想让玩家感受到什么——爽快、紧张、沉浸、治愈、成就、好奇、恐惧、社交归属？所有表现层和节奏都在服务这个目标。

## 二、用"设计支柱"决定深拆什么

九问答完后，找出这款游戏**最用力、最差异化的 2–3 个点**——那就是它的设计支柱。深拆支柱，其余维度略写即可。这样既保证深度，又不会每款都写成同样厚度的流水账。

判断支柱的问法：**如果抽掉某个设计，这游戏还成立吗？** 抽掉就垮的是支柱，抽掉无所谓的是装饰。

例：《杀戮尖塔》的支柱是"卡牌构筑深度 + 随机性与 build 平衡"，那就重拆第 3、4、6 问；它的叙事和商业化几乎不必着墨。《最后生还者》的支柱是"情绪叙事曲线 + 玩法与主题呼应"，重拆第 1、9 问，留存和赚钱根本不适用。

## 三、把任意游戏归位到最近的原型

拿不准品类时，用两三个问题快速归位，再去 `by-genre.md` 查对应原型簇的权重：

- **精通主要靠操作** → 操作技巧簇（动作/FPS/格斗/音游/竞速/平台跳跃）
- **精通主要靠决策** → 策略智力簇（战棋/4X/RTS/塔防/自走棋/构筑卡牌）
- **进度主要靠数值养成 + F2P** → 养成数值簇（RPG手游/ARPG刷宝/二游/放置/SLG）
- **核心是系统自洽与涌现** → 系统模拟簇（模拟经营/建造/生存/沙盒/城建）
- **核心是内容与情绪体验** → 内容体验簇（叙事/AVG/解谜/恐怖/步行模拟）
- **核心是人与人的对抗或协作** → 社交竞技簇（MOBA/大逃杀/竞技FPS/MMO社交/派对）
- **极简上手、泛用户、靠广告或关卡墙变现** → 休闲泛用户簇（三消/超休闲/合成/混合休闲）

## 四、混合与新品类怎么处理

现在大量游戏是混合体（如"Roguelike + 抽卡手游""开放世界 + 服务型运营"）。处理方法：

1. 用九问拆出它的多个支柱，分别落在哪些原型簇。
2. **取相关原型权重的并集**：哪些维度在任一支柱里重要，就都拆。
3. 一定要点明"**它用什么壳装什么核**"——比如"用 Roguelike 的局内体验做皮，内核是手游的长线养成与抽卡商业化"。这种"看穿包装"的判断，正是面试官眼里的设计 sense。

新品类（市面没有成熟参照的）同理：别慌着找标签，老老实实走九问 + 支柱定位，反而能拆得比套模板更透。
